I'm Tom Cocking, a UK-based IT professional. ExitCode0 is where I write up the things I've actually set up and had to work out for myself: Proxmox and LXC, Docker, Home Assistant and Zigbee, Tailscale, local LLMs with Ollama, and the scripts that stop me doing the same job twice.

Every post starts as something I needed. Most of them are written against the kit in my own homelab, including a Proxmox host and an always-on dev VM I work from over Tailscale. If a command is in a post, I ran it. If a step went wrong for me, the troubleshooting section says so.

Posts end with a section you can hand straight to a coding agent, because that's increasingly how I use other people's guides too.
